# AGENTS.md

Инструкция для новых ИИ-сессий и веток.

## Перед изменением

1. Прочитать `BRANDBOOK.md`.
2. Прочитать `docs/CREATIVE-MEMORY.md`.
3. Прочитать последние записи `docs/CREATIVE-LOG.md`.
4. Проверить `docs/DECISIONS.md` и `docs/SOURCES.md`.
5. Создать ветку `creative/<тема>`.

## Зафиксированные правила

- Текущая система: MOKO AI 2.3, утверждённый профиль сокола бога Гора и полный подготовленный владельцем пул Pantheon.
- Профиль всегда направлен вправо.
- Эталон формы: `assets/svg/source/moko-ai-horus-reference.svg`.
- SHA-256 эталона: `b353fee987999584dc9e8bf025da6dc02586b9f0163b6354f4aeb2ba70d4abbd`.
- Эталонный файл и его силуэт не изменять.
- Основной знак содержит 24 крупные low-poly грани.
- Основная композиция содержит красное кольцо и `AI` под клювом.
- `AI`: Jost SemiBold, контуры, масштаб 180%, transform `translate(210 232) scale(0.081 -0.081)`.
- Полная композиция используется от 64 px.
- Для 24–63 px используется `moko-ai-small.svg` без `AI` и граней.
- Производные файлы Гора воспроизводятся `scripts/build_horus_lowpoly.py`.
- Pantheon состоит из 120 готовых SVG из папки владельца `ПАНТЕОН`; корень — `assets/svg/pantheon/`.
- Файлы Pantheon нельзя перерисовывать, оптимизировать, переименовывать или изменять; целостность сверяется по `manifest.csv`.
- `scripts/build_pantheon_gallery.py` создаёт только HTML-галерею и не создаёт изображения.
- Исходные 10 каталогов коллекций и все 120 файлов публикуются без выборочного отбора.
- Подготовленный пул Pantheon не изменяет эталон Гора.
- Для основной системы MOKO AI использовать только утверждённую палитру из `brand.tokens.json`; цвета готовых SVG Pantheon сохранять как получены.
- Wordmark `MOKO`: официальные контуры Century Gothic.
- Заголовки: Jost. Основной текст: Inter.
- Мастер визуального файла: SVG.
- В SVG запрещены растры, внешние ресурсы, live text, скрипты, градиенты и фильтры.
- Публичный брендбук содержит только факты, файлы и запреты.

## Публикация

- Если существует `.secrets/moko-ai-brand-book-deploy`, не создавать новый deploy key.
- Для push использовать `scripts/push_github.sh`.
- Скрипт сам восстанавливает `origin`, использует постоянный локальный ключ и отправляет `main` и `v2.0.0`.
- `.secrets/` исключена из Git и не должна попадать в коммиты.

## После изменения

1. Запустить `python3 scripts/build_horus_lowpoly.py`.
2. Запустить `python3 scripts/build_pantheon_gallery.py`.
3. Запустить `python3 assets/svg/pantheon/verify_snapshot.py`.
4. Запустить `python3 scripts/export_rasters.py`, чтобы обновить PNG, JPG и WebP.
5. Обновить `manifest.json` при изменении состава файлов.
6. Добавить запись в `docs/CREATIVE-LOG.md`.
7. Обновить `docs/CREATIVE-MEMORY.md`, если появился повторно используемый вывод.
8. Добавить решение в `docs/DECISIONS.md`, если меняется система.
9. Обновить `CHANGELOG.md` и номер версии при релизе.
10. Запустить `python3 scripts/validate_svgs.py`.
11. Проверить 24 / 40 / 64 / 128 px для аватаров.
12. Заполнить `docs/BRANCH-HANDOFF-TEMPLATE.md` в PR.

История чата не является источником данных. Весь полезный контекст хранится в репозитории.

# Creative Memory

Актуальная выжимка для следующей ветки или новой ИИ-сессии. Обновлять, когда появляется вывод, полезный более чем для одного файла.

**Последнее обновление:** 2026-10-03 · **версия системы:** 1.0.0

## Контекст

- MOKO AI — ИИ-аккаунт внутри бренда MOKO Systems.
- Основная аудитория ожидает инженерную точность, а не развлекательного маскота.
- Официальный источник на момент старта — брендбук MOKO Systems v1.7.
- Все визуальные мастера создаются в SVG; растр допустим только как экспорт для платформы.

## Что уже работает

- Неизменённый знак MOKO остаётся главным объектом и обеспечивает узнаваемость.
- ИИ-контекст считывается через минимум дополнительных сигналов: сеть, узлы, `AI`.
- Шесть узлов дают цифровой характер, но не превращают знак в робота.
- `AI` собран path-контурами: аватар не зависит от шрифта.
- Для 24–63 px лучше полностью убрать сеть и шильдик, чем пытаться сохранить детали.
- Статусная точка полезна только при реальном состоянии сервиса.
- Светлая версия должна сохранять красные грани; менять их на чёрные не нужно.

## Устойчивые ограничения

- Не менять официальные path-данные и цвета граней.
- Не добавлять лицо или аксессуары поверх знака.
- Не использовать градиенты/3D/свечение как основной стиль.
- Не использовать зелёный, янтарный и синий без закреплённого смысла.
- Не писать «проверено», если проверка не выполнена.
- Не маскировать ответ ИИ под сообщение человека.

## Отвергнутые направления

1. **Робот-лицо с глазами.** Слишком буквально и конкурирует с фирменным знаком; у MOKO уже есть отдельный emoji robot для иллюстративных задач.
2. **Новая буква M, собранная из нейронных линий.** Ослабляет связь с исходным знаком.
3. **Градиентное красное свечение.** Не соответствует плоской геометрии и хуже переносится между носителями.
4. **Текст MOKO AI внутри маленького аватара.** Плохо читается; выбран короткий path-шильдик `AI`.
5. **Постоянная зелёная точка.** Статус без фактического состояния вводит в заблуждение.

## Проверки перед следующим релизом

- посмотреть основной аватар в круговой обрезке 64, 96 и 128 px;
- проверить светлую версию на белом и светло-сером окружении;
- убедиться, что статус не перекрывает знак при обрезке;
- прогнать `scripts/validate_svgs.py`;
- обновить manifest, log, decisions и changelog.

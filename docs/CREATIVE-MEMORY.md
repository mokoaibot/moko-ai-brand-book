# Creative Memory

Последнее обновление: 2026-10-27
Текущая версия: 2.2.0

## Утверждённая система

- Название: MOKO AI.
- Образ: профиль сокола — бог Гор.
- Направление: вправо.
- Силуэт: три раздельные формы.
- Контур: непрерывные кубические кривые Безье.
- Сетка: 24 крупные контрастные low-poly грани.
- Фон мастер-знака: прозрачный.
- Кольцо: фирменное красное, квадратный холст 384 × 384.
- Подпись `AI`: Jost SemiBold в контурах, масштаб 180%.
- Позиция `AI`: ниже и левее исходного положения, под клювом.
- Точный transform `AI`: `translate(210 232) scale(0.081 -0.081)`.

## Типографика

- Wordmark `MOKO`: официальные контуры Century Gothic.
- `AI`: Jost SemiBold в SVG-контурах.
- Заголовки сайта: локальный Jost Variable.
- Основной текст сайта: локальный Inter Variable.

## Размеры

- полная композиция: от 64 px;
- компактный аватар: 24–63 px;
- горизонтальный логотип: от 32 px по высоте;
- охранное поле: 12% ширины.

Компактная версия использует утолщённое кольцо и одноцветный силуэт без `AI` и граней.

## Статусы

- `#4caf7d` — доступен;

## Не возвращать

- сеть и шильдик версии 1.0;
- первый профиль с тяжёлой шеей и длинным клювом;
- профиль из исходных пирамид MOKO;
- фронтальную маску;
- гладкий самостоятельно интерпретированный профиль;
- неправильные силуэты с 308, 409, 625 или 931 гранью;
- утверждённую ранее мелкую сетку из 683 граней.

## Растровые загрузки

- для каждого SVG существует PNG в `exports/png/`;
- для каждого SVG существует JPG в `exports/jpg/`;
- для каждого SVG существует WebP в `exports/webp/`;
- PNG сохраняет прозрачность;
- JPG получает подходящий светлый или тёмный фон;
- WebP использует lossless-сжатие и сохраняет прозрачность;
- экспорт воспроизводится `python3 scripts/export_rasters.py`;
- SVG остаётся мастер-форматом.

## Проверка

- SVG не содержит растров, live text или внешних ресурсов;
- основной знак содержит 24 facet-полигона;
- утверждённый SHA-256 эталона не изменён;
- `python3 scripts/build_horus_lowpoly.py` воспроизводит производные ассеты Гора;
- `python3 scripts/build_pantheon.py` воспроизводит 11 образов Pantheon;
- `python3 scripts/validate_svgs.py` должен проходить без ошибок.
